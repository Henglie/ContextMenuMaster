# 界面截图放置说明

主 README「界面截图」一节按下列文件名引用图片。把截好的 PNG 放到本目录、用对应文件名即可自动显示，无需再改 Markdown。

| 文件名 | 截什么 | 建议内容 |
|---|---|---|
| `main-visual.png` | 可视化视图主界面 | 左侧栏 + 中间「现代菜单只读示意 → 经典菜单可编辑」并排，选一个项数较多的场景（如「文件」） |
| `list-view.png` | 列表视图 | 表格 + 复选框批量勾选 + 启停开关 + 改名/换图标按钮 |
| `win11-zone.png` | Windows 11 专区 | 经典/新版菜单状态卡 + 一键互换按钮 + 现代菜单可视化预览 |
| `batch-magic.png` | 批量魔法 | 勾选若干项 + 批量追加后缀面板（预设「 喵~」「 ★」） |
| `filetype.png` | 文件类型场景 | 输入某扩展名（如 `.zip`）扫描后聚合的四类根 + 启停 |

## 截图建议

- 窗口调到约 1100×720，让侧栏和主区都完整入镜。
- 界面语言用简体中文（右上角切换）。
- 截「窗口」而非整屏：`Alt + PrintScreen` 只截当前窗口，或用截图工具框选窗口区域。
- 提权窗口若用系统自带截图工具截出来是黑的，改用 `Win + Shift + S`（截图和草图）框选，或 Xbox Game Bar（`Win + G`）录屏截帧。
- 尺寸别太大，单张控制在 1600px 宽以内，PNG 即可。

放好图后，主 README 的图会自动出现。若只放了部分图，把主 README 里对应的未截图条目删掉即可。
