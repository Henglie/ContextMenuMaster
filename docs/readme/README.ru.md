> Верните себе управление контекстным меню в Windows 11.

**Управление контекстным меню** — это инструмент повышения продуктивности для рабочего стола Windows. Он возвращает в ваши руки захламлённое, свёрнутое и забитое разными программами контекстное меню: визуально переименовывайте пункты и меняйте значки, управляйте пакетно с помощью флажков, одним щелчком возвращайте скрытое в Windows 11 классическое меню, охватывая все сценарии контекстного меню — рабочий стол / файл / папка / диск / Корзина / Win+X / Отправить / Создать / перетаскивание.

Полностью локальная работа, автоматическое резервное копирование реестра перед любой операцией записи, все операции обратимы в любой момент. Запустите от имени администратора, чтобы управлять пунктами меню в области системы и всех пользователей (HKLM).

> [!WARNING]
> **Расширение оболочки для мультимедиа (`CmmShellExt.dll`) в настоящее время является экспериментальным.** Это внутрипроцессное COM-расширение оболочки, которое вступает в силу только после ручной регистрации от имени администратора командой `regsvr32 CmmShellExt.dll`; после регистрации при щелчке правой кнопкой по файлу отображаются пункты меню с реальными эскизами. Эта часть ещё не прошла широкой проверки на реальных машинах и может вести себя нестабильно — или вовсе не появляться — в отдельных системах, для отдельных типов файлов или в окружениях с защитным ПО. В неё встроены предохранители (архивы более 200MB или перечисление дольше 800ms автоматически понижаются до обычного пункта меню, так что меню никогда не зависает), но всё же не рекомендуется оставлять её зарегистрированной надолго в важных окружениях. Функции управления меню основного приложения от неё не зависят и могут использоваться самостоятельно.

| Сценарий | Без этого инструмента | С этим инструментом |
|---|---|---|
| Контекстное меню Win11 слишком лаконичное, частые пункты свёрнуты в «Показать дополнительные параметры» | Каждый раз лишний щелчок и лишнее ожидание | Одним щелчком вернитесь к полному классическому меню, эффект мгновенный |

## Основные возможности

- **Охват всех сценариев контекстного меню**: одна боковая панель раскладывает по вертикали все сценарии контекстного меню; один щелчок — и вы переключились —
  - **Сценарии реестра**: пустой рабочий стол, файл, папка, пустая область папки, диск, Корзина, все файловые объекты, Этот компьютер, библиотеки.
  - **Меню Win+X**: управление тем расширенным меню «щелчок правой кнопкой по кнопке Пуск / Win+X» (отображение по группам, включение/отключение, добавление своих пунктов, удаление).
  - **Отправить (SendTo)**: управление пунктами подменю «Отправить» контекстного меню — включение/отключение, добавление, удаление.
  - **Создать (ShellNew)**: управление тем, какие типы файлов появляются в подменю «Создать» контекстного меню, с включением/отключением каждого пункта.
  - **Обработчики перетаскивания (DragDrop)**: управление расширениями меню, всплывающими при перетаскивании файлов правой кнопкой.
  - **Открыть с помощью (Open with)**: просмотр приложений, зарегистрированных как кандидаты для «Открыть с помощью» (только для чтения).
- **Синхронизация двух представлений в реальном времени**
  - **Визуальное представление (WYSIWYG)**: имитирует в масштабе 1:1 настоящее контекстное меню Windows; щёлкните по названию для переименования, по значку — для смены значка, **щёлкните правой кнопкой по пункту меню, чтобы открыть меню действий (переименовать / сменить значок / включить или отключить)** — что видите, то и получаете.
  - **Представление списком (List View)**: традиционная таблица с пакетным выбором флажками, переключателями включения/отключения, кнопками переименования и смены значка — удобно для управления набором пунктов за один раз.
- **Пакетная магия**: выберите несколько пунктов меню и одним щелчком добавьте им всем один и тот же суффикс (например, « мяу~», « ★»), также настраиваемый.
- **Раздел Windows 11**
  - **Переключение классического меню одним щелчком**: записывает пустой `InprocServer32` в HKCU, чтобы отключить расширения нового меню, из-за чего Проводник откатывается к классическому меню Win10; и изящно перезапускает `explorer.exe`, меню применяется мгновенно, без выхода и повторного входа. Ещё один щелчок — и всё восстановлено.
  - **Расширения нового меню (в разработке)**: зарезервирован интерфейс для сканирования и перехвата пунктов-расширений `IExplorerCommand` из разреженных пакетов (MSIX) Win11.
- **Многоязычность**: при первом запуске автоматически выбирается по языку отображения системы (китайский упрощённый/традиционный, для всего остального — английский); интерфейс можно переключать в любой момент.
- **Полностью локально и обратимо**: только чтение и запись в реестр текущего пользователя, без подключения к интернету и без отправки данных; удаление ключа восстанавливает системные значения по умолчанию.

## Быстрый старт

1. Скачайте zip нужной архитектуры из [Releases](https://github.com/Henglie/ContextMenuMaster/releases) (для большинства компьютеров выбирайте x64) и распакуйте в любой каталог.
2. Дважды щёлкните `ContextMenuMaster.exe` и в появившемся запросе UAC нажмите «Да», чтобы предоставить права администратора (нужны для чтения и записи пунктов меню, которые сторонние программы записывают в `HKLM`; без повышения прав можно менять только пункты текущего пользователя).
3. Без установки и без интернета. При первом запуске язык интерфейса выбирается автоматически по языку системы; в правом верхнем углу в любой момент можно переключить упрощённый / традиционный китайский / English.

## Как пользоваться

### 1 · Выбор сценария

Левая боковая панель раскладывает по вертикали все сценарии контекстного меню, разделённые на три группы:

- **Частые сценарии**: пустой рабочий стол, файл, папка, пустая область папки, диск, Корзина, все файловые объекты, Этот компьютер, библиотеки — соответствуют меню, которые вы видите при щелчке правой кнопкой по разным объектам.
- **Подменю**: Отправить, Создать, перетаскивание, Открыть с помощью, типы файлов — подменю контекстного меню и управление по расширениям.
- **Быстрые входы**: Win+X (расширенное меню кнопки Пуск, вызываемое правой кнопкой).

Вверху есть ещё два отдельных входа: **Раздел Windows 11** и **Rich Media**. Щёлкните любой сценарий — и будут отсканированы его настоящие пункты меню; на ярлыке в углу отображается число пунктов.

### 2 · Изменение меню

Два представления, переключаемых в правом верхнем углу, с синхронизацией данных в реальном времени:

- **Визуальное представление**: имитирует в масштабе 1:1 контекстное меню Windows.
  - Щёлкните по **названию** пункта меню, чтобы переименовать его напрямую; щёлкните по **значку**, чтобы сменить его.
  - **Щёлкните правой кнопкой** по любому пункту меню, чтобы открыть меню действий: переименовать / сменить значок / включить или отключить / удалить (для созданных вами пунктов).
  - Сторона современного меню — это схема только для чтения (современное меню Win11 не управляется реестром, см. пояснение ниже); сторона классического меню редактируема.
- **Представление списком**: традиционная таблица, удобная для пакетных операций.
  - В каждой строке есть переключатель включения/отключения и кнопки переименования / смены значка.
  - Отметив несколько строк, используйте **пакетную магию**, чтобы одним щелчком добавить им всем единообразный суффикс (например, « ★»), также настраиваемый.

Переименование / смена значка / включение или отключение встроенных системных пунктов сопровождается повторным подтверждением; перед каждой записью в реестр автоматически создаётся резервная копия в `%LOCALAPPDATA%\ContextMenuMaster\backups\`, чтобы можно было восстановить, если что-то сломается.

### 3 · Возврат классического меню (Windows 11)

Зайдите в **Раздел Windows 11** и нажмите «Переключить на классическое меню»: программа отключит расширения нового меню и изящно перезапустит `explorer.exe`; контекстное меню мгновенно вернётся к полному стилю Win10, без выхода и повторного входа. Ещё один щелчок — и новое меню восстановлено.

### 4 · Создание собственных пунктов меню

На панели инструментов представления списком нажмите «Новый пункт меню» и заполните отображаемое имя, тип выполнения (запустить программу / открыть папку / открыть URL / произвольная командная строка), путь к цели, значок (необязательно, поддерживается любое изображение с автоматическим преобразованием в ICO) и положение (сверху / снизу). Созданные вами пункты имеют собственную метку и могут быть изменены или удалены в любой момент; удаление затрагивает только пункты, созданные этим инструментом, и не касается системных ассоциаций.

> **О современном меню Win11**: новое контекстное меню Windows 11 принимает только расширения `IExplorerCommand` с идентификацией пакета (MSIX / разреженный пакет); традиционные пункты меню из реестра все свёрнуты в классическое меню внутри «Показать дополнительные параметры» — это проектное решение системы, не связанное с правами. Поэтому данный инструмент управляет уровнем классического меню; чтобы вернуть частые пункты на верхний уровень, используйте «Возврат классического меню» выше.

## Многоязычность

Бэкенд на C++ с помощью Win32 API считывает язык отображения системы по умолчанию и внедряет его во фронтенд перед созданием страницы WebView2:

- Система на китайском (zh-CN / zh-TW / zh-HK и т. д.) → интерфейс отрисовывается на китайском, упрощённом или традиционном.
- Система на любом другом языке → всегда откат к английскому (en).

В правом верхнем углу интерфейса в любой момент можно вручную переключить упрощённый / традиционный китайский / English; выбор записывается в локальное хранилище.

## Технологический стек и архитектура

| Слой | Выбор | Описание |
|---|---|---|
| Движок бэкенда | Современный C++17 / MSVC | Прямые нативные вызовы Win32 API |
| Слой представления | Microsoft Edge WebView2 | Заголовочная библиотека webview размещает встроенный в систему WebView2 |
| Мост связи | WebMessage / postMessage | `w.bind` открывает функции бэкенда, фронтенд вызывает через `await window.fn()` |
| Интерфейс | Vue 3 (локально) | Приложение из одного файла |
| Визуальная система | FairyGlass | Система дизайна «жидкое стекло» в приглушённо-синем тёмном тоне, токены встроены прямо в `ui/index.html` |
| Сборка | CMake + Ninja | Распознаётся функцией «Открыть папку» в VS2022 |

**Архитектура: Core-Shell (универсальное ядро + нативная оболочка)**, как и в родственном проекте FairySave: `src/platform/windows` — привилегированный слой Win32 (определение i18n, перехват меню реестра), а `ui/` — слой представления.

**Совместимость**: Windows 10 / 11 (перехват классического меню — функция Win11). Требуется среда выполнения WebView2 (встроена в Win10/11).

## Разработка и сборка

**Среда**: VS2022 (с рабочей нагрузкой для настольной разработки на C++, CMake, Ninja и Windows SDK) + среда выполнения WebView2.

**Простейший способ**: в VS2022 выберите «Открыть локальную папку» и укажите этот каталог; он автоматически прочитает `CMakePresets.json`, распознает как проект CMake, а вы выберете пресет `windows-debug` или `windows-release` для сборки и запуска.

**Способ через командную строку** (в среде vcvars64):

```bat
cmake --preset windows-release
cmake --build build/release
```

Результаты:

- `build/release/bin/ContextMenuMaster.exe` — основная программа с GUI (подсистема WIN32, без консоли).
- `build/release/bin/CmmCli.exe` — отладочный зонд командной строки (для проверки бэкенда, не для конечного пользователя).

> После изменения `ui/`, если вы правили только HTML, нужно вручную синхронизировать `ui/` в каталог `ui/` рядом с exe (POST_BUILD в CMake срабатывает только при перекомпоновке).

## Конфиденциальность и безопасность

- **Полностью локально**: без подключения к интернету и без отправки какого-либо содержимого.
- **Требуются права администратора**: пункты меню сторонних программ часто регистрируются в `HKLM` (все пользователи), и их метки отключения тоже в основном находятся в `HKLM`, в пользовательском режиме их не изменить. Поэтому при запуске программа запрашивает права администратора, чтобы напрямую читать и записывать в реальное расположение пунктов меню в реестре, обеспечивая возможность «включать/отключать и переименовывать все пункты».
- **Автоматическое резервное копирование перед записью**: перед каждым изменением реестра сначала выполняется `reg export` соответствующего ключа в локальный `%LOCALAPPDATA%\ContextMenuMaster\backups\`.
- **Обратимо**: перехват классического меню в любой момент восстанавливается удалением ключа; включение/отключение работает через «добавить-удалить метку / перенести в зеркало отключённых» и может быть возвращено в исходное состояние; удалённые пункты всегда отправляются в Корзину. Системные файлы не повреждаются.
