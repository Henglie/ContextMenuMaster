> จัดการเมนูคลิกขวาของคุณใหม่บน Windows 11

**ผู้จัดการเมนูคลิกขวา** เป็นเครื่องมือเพิ่มประสิทธิภาพบนเดสก์ท็อป Windows มันคืนเมนูคลิกขวาที่รกรุงรัง ถูกยุบซ่อน และถูกซอฟต์แวร์ต่าง ๆ ยัดเยียดจนล้น กลับคืนสู่มือคุณ ทั้งเปลี่ยนชื่อและไอคอนแบบเห็นภาพ จัดการเลือกทีละหลายรายการ เรียกคืนเมนูคลาสสิกที่ถูกซ่อนของ Windows 11 ด้วยคลิกเดียว และครอบคลุมทุกฉากคลิกขวา ทั้งเดสก์ท็อป / ไฟล์ / โฟลเดอร์ / ไดรฟ์ / ถังรีไซเคิล / Win+X / ส่งไปยัง / สร้าง / ลากแล้วปล่อย

ทำงานภายในเครื่องล้วน ๆ สำรองข้อมูลรีจิสทรีอัตโนมัติก่อนการเขียนทุกครั้ง และทุกการกระทำย้อนกลับได้ตลอดเวลา เรียกใช้ในฐานะผู้ดูแลระบบเพื่อจัดการรายการเมนูในขอบเขตระบบและผู้ใช้ทั้งหมด (HKLM)

> [!WARNING]
> **ส่วนขยายเชลล์แบบริชมีเดีย (`CmmShellExt.dll`) ยังอยู่ในขั้นทดลอง** เป็นส่วนขยายเชลล์ COM แบบ in-process ที่จะมีผลก็ต่อเมื่อคุณลงทะเบียนด้วยตนเองในฐานะผู้ดูแลระบบด้วย `regsvr32 CmmShellExt.dll` เท่านั้น เมื่อลงทะเบียนแล้ว การคลิกขวาที่ไฟล์จะแสดงรายการเมนูพร้อมภาพขนาดย่อจริง ส่วนนี้ยังไม่ได้รับการตรวจสอบอย่างกว้างขวางบนเครื่องจริง และอาจทำงานไม่เสถียร หรือไม่ปรากฏเลย บนบางระบบ บางประเภทไฟล์ หรือบางสภาพแวดล้อมของซอฟต์แวร์ความปลอดภัย มันมาพร้อมมาตรการป้องกัน (ไฟล์บีบอัดที่ใหญ่กว่า 200MB หรือการแจกแจงที่นานเกิน 800ms จะลดระดับเป็นรายการเมนูธรรมดาโดยอัตโนมัติ เพื่อไม่ให้เมนูค้าง) แต่ก็ยังไม่แนะนำให้ปล่อยลงทะเบียนไว้ระยะยาวในสภาพแวดล้อมสำคัญ ฟีเจอร์จัดการเมนูของแอปหลักไม่ได้ขึ้นอยู่กับส่วนนี้ และสามารถใช้งานได้ด้วยตัวเอง

## ฟังก์ชันหลัก

- **ครอบคลุมทุกฉากคลิกขวา**: แถบด้านข้างหนึ่งอันวางเรียงทุกฉากคลิกขวาตามแนวตั้ง คลิกเดียวก็สลับ——
  - **ฉากรีจิสทรี**: พื้นที่ว่างเดสก์ท็อป ไฟล์ โฟลเดอร์ พื้นที่ว่างโฟลเดอร์ ไดรฟ์ ถังรีไซเคิล อ็อบเจ็กต์ไฟล์ทั้งหมด พีซีเครื่องนี้ ไลบรารี
  - **เมนู Win+X**: จัดการเมนูขั้นสูงจาก "คลิกขวาปุ่ม Start / Win+X" (แสดงเป็นกลุ่ม เปิด/ปิด เพิ่มรายการกำหนดเอง ลบ)
  - **ส่งไปยัง (SendTo)**: จัดการรายการในเมนูย่อย "ส่งไปยัง" ของคลิกขวา เปิด/ปิด เพิ่ม ลบได้
  - **สร้าง (ShellNew)**: จัดการว่าประเภทไฟล์ใดปรากฏในเมนูย่อย "สร้าง" ของคลิกขวา เปิด/ปิดทีละรายการ
  - **ตัวจัดการการลากแล้วปล่อย (DragDrop)**: จัดการส่วนขยายเมนูที่ปรากฏเมื่อลากแล้วปล่อยไฟล์ด้วยคลิกขวา
  - **เปิดด้วย (Open with)**: ดูแอปที่ลงทะเบียนเป็นตัวเลือก "เปิดด้วย" (อ่านอย่างเดียว)
- **สองมุมมองซิงค์แบบเรียลไทม์**
  - **มุมมองแบบเห็นภาพ (WYSIWYG)**: จำลองเมนูคลิกขวาจริงของ Windows แบบ 1:1 คลิกที่ชื่อเพื่อเปลี่ยนชื่อ คลิกที่ไอคอนเพื่อเปลี่ยนไอคอน **คลิกขวาที่รายการเมนูเพื่อเปิดเมนูปฏิบัติการ (เปลี่ยนชื่อ / เปลี่ยนไอคอน / เปิดใช้งานหรือปิดใช้งาน)** เห็นอย่างไรได้อย่างนั้น
  - **มุมมองรายการ (List View)**: ตารางแบบดั้งเดิม กล่องกาเครื่องหมายเลือกทีละหลายรายการ มีทั้งสวิตช์เปิด/ปิด ปุ่มเปลี่ยนชื่อและเปลี่ยนไอคอนครบครัน เหมาะสำหรับจัดการรายการเมนูทีละหลายรายการในครั้งเดียว
- **เวทมนตร์แบบกลุ่ม**: เลือกรายการเมนูหลายรายการ แล้วเติมส่วนต่อท้ายเดียวกันให้ทั้งหมดด้วยคลิกเดียว (เช่น " เหมียว~" " ★") หรือกำหนดเองก็ได้
- **โซน Windows 11**
  - **สลับเมนูคลาสสิกด้วยคลิกเดียว**: เขียน `InprocServer32` ว่างลงใน HKCU เพื่อให้ส่วนขยายเมนูรุ่นใหม่ใช้งานไม่ได้ ทำให้ตัวจัดการไฟล์ถอยกลับไปใช้เมนูคลาสสิกแบบ Win10 พร้อมรีสตาร์ท `explorer.exe` อย่างนุ่มนวล เมนูมีผลทันที ไม่ต้องออกจากระบบแล้วเข้าใหม่ คลิกอีกครั้งก็คืนสภาพเดิม
  - **ส่วนขยายเมนูรุ่นใหม่ (กำลังพัฒนา)**: สำรองอินเทอร์เฟซไว้สำหรับสแกนและควบคุมรายการส่วนขยาย `IExplorerCommand` แบบแพ็กเกจกระจาย (MSIX) ของ Win11
- **หลายภาษา**: เมื่อเปิดครั้งแรกจะเลือกตามภาษาที่แสดงของระบบอัตโนมัติ (จีนตัวย่อ/ตัวเต็ม ที่เหลือใช้ภาษาอังกฤษทั้งหมด) และเปลี่ยนส่วนติดต่อผู้ใช้ได้ตลอดเวลา
- **ภายในเครื่องล้วน ๆ ย้อนกลับได้**: อ่านและเขียนเฉพาะรีจิสทรีของผู้ใช้ปัจจุบัน ไม่เชื่อมต่ออินเทอร์เน็ต ไม่อัปโหลด ลบคีย์ก็กลับไปเป็นค่าเริ่มต้นของระบบ

## เริ่มต้นใช้งานอย่างรวดเร็ว

1. ดาวน์โหลด zip ตามสถาปัตยกรรมที่ตรงกันจาก [Releases](https://github.com/Henglie/ContextMenuMaster/releases) (คอมพิวเตอร์ส่วนใหญ่เลือก x64) แล้วแตกไฟล์ไปยังไดเรกทอรีใดก็ได้
2. ดับเบิลคลิก `ContextMenuMaster.exe` แล้วคลิก "ใช่" ในกล่องแจ้ง UAC ที่ปรากฏเพื่อให้สิทธิ์ผู้ดูแลระบบ (ใช้สำหรับอ่านและเขียนรายการเมนูที่ซอฟต์แวร์ภายนอกเขียนไว้ใน `HKLM` ถ้าไม่ยกระดับสิทธิ์จะแก้ได้เฉพาะรายการของผู้ใช้ปัจจุบันเท่านั้น)
3. ไม่ต้องติดตั้ง ไม่ต้องเชื่อมต่ออินเทอร์เน็ต การเรียกใช้ครั้งแรกจะเลือกภาษาส่วนติดต่อผู้ใช้ตามภาษาระบบอัตโนมัติ มุมขวาบนสลับระหว่างตัวย่อ / ตัวเต็ม / English ได้ตลอดเวลา

## วิธีใช้งาน

### 1 · เลือกฉาก

แถบด้านซ้ายวางเรียงทุกฉากคลิกขวาตามแนวตั้ง แบ่งเป็นสามกลุ่ม:

- **ฉากที่ใช้บ่อย**: พื้นที่ว่างเดสก์ท็อป ไฟล์ โฟลเดอร์ พื้นที่ว่างโฟลเดอร์ ไดรฟ์ ถังรีไซเคิล อ็อบเจ็กต์ไฟล์ทั้งหมด พีซีเครื่องนี้ ไลบรารี —— ตรงกับเมนูที่คุณเห็นเมื่อคลิกขวาบนอ็อบเจ็กต์ต่าง ๆ
- **เมนูระดับสอง**: ส่งไปยัง สร้าง ลากแล้วปล่อย เปิดด้วย ประเภทไฟล์ —— เมนูย่อยในเมนูคลิกขวาและการจัดการตามนามสกุลไฟล์
- **ทางลัด**: Win+X (เมนูขั้นสูงจากการคลิกขวาปุ่ม Start)

ด้านบนยังมีทางเข้าแยกอีกสองอย่างคือ **โซน Windows 11** และ **สื่อสมบูรณ์** คลิกฉากใดก็ได้เพื่อสแกนรายการเมนูจริงของฉากนั้น ป้ายมุมของแท็บจะแสดงจำนวนรายการ

### 2 · แก้เมนู

มีสองมุมมอง สลับได้ที่มุมขวาบน ข้อมูลซิงค์แบบเรียลไทม์:

- **มุมมองแบบเห็นภาพ**: จำลองเมนูคลิกขวาของ Windows แบบ 1:1
  - คลิก **ชื่อ** รายการเมนูเพื่อเปลี่ยนชื่อโดยตรง คลิก **ไอคอน** เพื่อเปลี่ยนไอคอน
  - **คลิกขวา** ที่รายการเมนูใดก็ได้เพื่อเปิดเมนูปฏิบัติการ: เปลี่ยนชื่อ / เปลี่ยนไอคอน / เปิดใช้งานหรือปิดใช้งาน / ลบ (รายการที่สร้างเอง)
  - ฝั่งเมนูสมัยใหม่เป็นตัวอย่างแบบอ่านอย่างเดียว (เมนูสมัยใหม่ของ Win11 ไม่ได้ควบคุมด้วยรีจิสทรี ดูคำอธิบายด้านล่าง) ส่วนฝั่งเมนูคลาสสิกแก้ไขได้
- **มุมมองรายการ**: ตารางแบบดั้งเดิม เหมาะกับการทำงานทีละหลายรายการ
  - แต่ละแถวมีสวิตช์เปิด/ปิด ปุ่มเปลี่ยนชื่อ / เปลี่ยนไอคอน
  - เมื่อกาหลายแถวแล้ว ใช้ **เวทมนตร์แบบกลุ่ม** เติมส่วนต่อท้ายเดียวกันให้ทั้งหมดด้วยคลิกเดียว (เช่น " ★") หรือกำหนดเองก็ได้

การเปลี่ยนชื่อ / เปลี่ยนไอคอน / เปิดปิดสำหรับรายการที่มากับระบบจะมีการยืนยันซ้ำ ก่อนเขียนรีจิสทรีทุกครั้งจะสำรองข้อมูลอัตโนมัติไปยัง `%LOCALAPPDATA%\ContextMenuMaster\backups\` หากแก้พังก็คืนค่าได้

### 3 · เรียกคืนเมนูคลาสสิก (Windows 11)

เข้า **โซน Windows 11** แล้วคลิก "สลับเป็นเมนูคลาสสิก" โปรแกรมจะทำให้ส่วนขยายเมนูรุ่นใหม่ใช้งานไม่ได้และรีสตาร์ท `explorer.exe` อย่างนุ่มนวล เมนูคลิกขวาจะกลับไปเป็นรูปแบบเต็มของ Win10 ในพริบตา ไม่ต้องออกจากระบบแล้วเข้าใหม่ คลิกอีกครั้งก็คืนกลับเมนูรุ่นใหม่

### 4 · สร้างรายการเมนูของตัวเอง

ที่แถบเครื่องมือของมุมมองรายการ คลิก "สร้างรายการเมนู" กรอกชื่อที่แสดง ประเภทการทำงาน (เรียกใช้โปรแกรม / เปิดโฟลเดอร์ / เปิดเว็บไซต์ / บรรทัดคำสั่งกำหนดเอง) เส้นทางเป้าหมาย ไอคอน (ไม่บังคับ รองรับรูปภาพใด ๆ แปลงเป็น ICO อัตโนมัติ) ตำแหน่ง (บนสุด / ล่างสุด) รายการที่สร้างเองมีเครื่องหมายเฉพาะ แก้ไขหรือลบได้ตลอดเวลา การลบจะล้างเฉพาะรายการที่เครื่องมือนี้สร้างเท่านั้น ไม่แตะการเชื่อมโยงของระบบ

> **เกี่ยวกับเมนูสมัยใหม่ของ Win11**: เมนูคลิกขวารุ่นใหม่ของ Windows 11 รับเฉพาะส่วนขยาย `IExplorerCommand` ที่มีเครื่องหมายแพ็กเกจ (MSIX / แพ็กเกจกระจาย) เท่านั้น รายการเมนูรีจิสทรีแบบดั้งเดิมจะถูกยุบเข้าไปในเมนูคลาสสิกภายใต้ "แสดงตัวเลือกเพิ่มเติม" ทั้งหมด —— นี่คือการออกแบบของระบบ ไม่เกี่ยวกับสิทธิ์ ดังนั้นเครื่องมือนี้จัดการที่ชั้นเมนูคลาสสิก หากอยากให้รายการที่ใช้บ่อยกลับไปอยู่ชั้นบนสุด ให้ใช้ "เรียกคืนเมนูคลาสสิก" ด้านบน

## หลายภาษา

แบ็กเอนด์ C++ ใช้ Win32 API อ่านภาษาที่แสดงเริ่มต้นของระบบ แล้วฉีดให้ฟรอนต์เอนด์ก่อนสร้างหน้า WebView2:

- ระบบเป็นภาษาจีน (zh-CN / zh-TW / zh-HK ฯลฯ) → แสดงส่วนติดต่อผู้ใช้ภาษาจีนตามตัวย่อหรือตัวเต็ม
- ระบบเป็นภาษาอื่นใด → ถอยกลับไปใช้ภาษาอังกฤษ (en) ทั้งหมด

มุมขวาบนของส่วนติดต่อผู้ใช้สลับด้วยตนเองระหว่างตัวย่อ / ตัวเต็ม / English ได้ตลอดเวลา ตัวเลือกจะถูกบันทึกไว้ในที่จัดเก็บภายในเครื่อง

## เทคโนโลยีและสถาปัตยกรรม

| ชั้น | ตัวเลือก | คำอธิบาย |
|---|---|---|
| เอนจินแบ็กเอนด์ | C++17 สมัยใหม่ / MSVC | เรียก Win32 API แบบดั้งเดิมโดยตรง |
| ชั้นการแสดงผล | Microsoft Edge WebView2 | ไลบรารีเฮดเดอร์เดียว webview รองรับ WebView2 ที่มากับระบบ |
| สะพานการสื่อสาร | WebMessage / postMessage | `w.bind` เปิดเผยฟังก์ชันแบ็กเอนด์ ฟรอนต์เอนด์เรียกด้วย `await window.fn()` |
| ส่วนติดต่อผู้ใช้ | Vue 3 (ในเครื่อง) | แอปไฟล์เดียว |
| ระบบภาพ | FairyGlass | ระบบออกแบบกระจกเหลวโทนมืดสีน้ำเงินอ่อน โทเคนถูกคัดลอกแบบอินไลน์เข้าไปใน `ui/index.html` |
| การสร้าง | CMake + Ninja | VS2022 "เปิดโฟลเดอร์" ก็รู้จักทันที |

**สถาปัตยกรรม: Core-Shell (เคอร์เนลสากล + เชลล์ดั้งเดิม)** สอดคล้องกับโครงการพี่น้อง FairySave: `src/platform/windows` คือชั้นสิทธิพิเศษ Win32 (การตรวจจับ i18n การควบคุมเมนูรีจิสทรี) ส่วน `ui/` คือชั้นการแสดงผล

**ความเข้ากันได้**: Windows 10 / 11 (การควบคุมเมนูคลาสสิกเป็นคุณสมบัติของ Win11) ต้องมี WebView2 รันไทม์ (Win10/11 มีมาให้)

## การพัฒนาและการสร้าง

**สภาพแวดล้อม**: VS2022 (รวมภาระงานเดสก์ท็อป C++, CMake, Ninja, Windows SDK) + WebView2 รันไทม์

**วิธีที่ง่ายที่สุด**: VS2022 "เปิดโฟลเดอร์ในเครื่อง" เลือกไดเรกทอรีนี้ จะอ่าน `CMakePresets.json` อัตโนมัติและรู้จักว่าเป็นโครงการ CMake เลือกพรีเซ็ต `windows-debug` หรือ `windows-release` เพื่อสร้างและเรียกใช้

**วิธีบรรทัดคำสั่ง** (ในสภาพแวดล้อม vcvars64):

```bat
cmake --preset windows-release
cmake --build build/release
```

ผลผลิต:

- `build/release/bin/ContextMenuMaster.exe` —— โปรแกรมหลัก GUI (ระบบย่อย WIN32 ไม่มีคอนโซล)
- `build/release/bin/CmmCli.exe` —— หัววัดดีบักบรรทัดคำสั่ง (ใช้ตรวจสอบแบ็กเอนด์ ไม่ได้มุ่งเป้าผู้ใช้ปลายทาง)

> หลังแก้ `ui/` แล้ว หากแก้เฉพาะ HTML ต้องซิงค์ `ui/` ไปยังไดเรกทอรี `ui/` ที่อยู่ข้าง exe ด้วยตนเอง (POST_BUILD ของ CMake จะทำงานเฉพาะเมื่อลิงก์ใหม่)

## ความเป็นส่วนตัวและความปลอดภัย

- **ภายในเครื่องล้วน ๆ**: ไม่เชื่อมต่ออินเทอร์เน็ต ไม่อัปโหลดเนื้อหาใด ๆ
- **ต้องการสิทธิ์ผู้ดูแลระบบ**: รายการเมนูของซอฟต์แวร์ภายนอกมักลงทะเบียนไว้ใน `HKLM` (ผู้ใช้ทั้งหมด) และเครื่องหมายปิดใช้งานของมันก็อยู่ใน `HKLM` เป็นส่วนใหญ่ ซึ่งโหมดผู้ใช้ล้วน ๆ แก้ไม่ได้ ดังนั้นตอนเริ่มโปรแกรมจึงขอสิทธิ์ผู้ดูแลระบบ เพื่ออ่านและเขียนตำแหน่งรีจิสทรีจริงที่รายการเมนูอยู่โดยตรง เพื่อรองรับ "ทุกรายการเปิดปิด / เปลี่ยนชื่อได้"
- **สำรองอัตโนมัติก่อนเขียน**: ก่อนแก้รีจิสทรีทุกครั้งจะ `reg export` สำรองคีย์ที่เกี่ยวข้องไปยัง `%LOCALAPPDATA%\ContextMenuMaster\backups\` ในเครื่อง
- **ย้อนกลับได้**: การควบคุมเมนูคลาสสิกลบคีย์ก็คืนสภาพได้ตลอดเวลา การเปิดปิดใช้ "เพิ่มเครื่องหมายลบ / ย้ายไปภาพปิดใช้งาน" ย้ายกลับได้อย่างเดิม การลบรายการจะส่งไปถังรีไซเคิลเสมอ ไม่ทำลายไฟล์ระบบ
