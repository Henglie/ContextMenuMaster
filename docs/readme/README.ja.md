> Windows 11 で右クリックメニューをもう一度あなたの手に。

**右クリックメニューマネージャー**は Windows デスクトップ向けの効率化ツールです。散らかり、折りたたまれ、さまざまなソフトに埋め尽くされたコンテキストメニューをあなたの手に取り戻します。ビジュアルに名前とアイコンを変更し、まとめてチェックして管理し、Windows 11 が隠したクラシックメニューをワンクリックで呼び戻します。さらにデスクトップ / ファイル / フォルダー / ドライブ / ごみ箱 / Win+X / 送る / 新規作成 / ドラッグ＆ドロップなど、あらゆる右クリックの場面をカバーします。

完全ローカル動作で、書き込み操作の前にレジストリを自動バックアップし、すべての操作はいつでも元に戻せます。システムおよび全ユーザー（HKLM）範囲のメニュー項目を管理するには、管理者として実行してください。

> [!WARNING]
> **リッチメディア右クリック拡張（`CmmShellExt.dll`）は現在実験的な機能です。** これはプロセス内 COM シェル拡張で、管理者として手動で `regsvr32 CmmShellExt.dll` を実行して登録した後にのみ有効になります。登録後、ファイルを右クリックすると実際のサムネイル付きのメニュー項目が表示されます。この部分はまだ実機で広く検証されておらず、一部のシステム、ファイル種類、セキュリティソフト環境では動作が不安定になったり、まったく表示されなかったりする場合があります。ガードレール（圧縮ファイルが 200MB を超える、または列挙が 800ms を超えると自動的に通常のメニュー項目に降格し、右クリックメニューが固まらない）を内蔵していますが、それでも重要な環境で長期間登録したままにすることは推奨しません。本体アプリのメニュー管理機能はこれに依存しておらず、単独で安心して使用できます。

## どんな課題を解決するか

| 場面 | 本ツールなし | 本ツールあり |
|---|---|---|
| Win11 の右クリックメニューがシンプルすぎて、よく使う項目が「その他のオプションを表示」に折りたたまれる | 毎回一手間、一瞬待つ | ワンクリックで完全なクラシックメニューに戻り、即座に反映 |

| メニュー項目を見やすい名前やアイコンに変えたい | レジストリ構造を理解しないと触れない | ビジュアルビューでクリックひとつ |
| 一群のメニュー項目にまとめて印を付けたい | 一つずつ手作業 | 一括マジック、チェック後ワンクリックでサフィックスを追加 |

## 主な機能

- **すべての右クリック場面をカバー**：一つのサイドバーにすべての右クリック場面を縦に並べ、クリックひとつで切り替え——
  - **レジストリ場面**：デスクトップの空白部分、ファイル、フォルダー、フォルダーの空白部分、ドライブ、ごみ箱、すべてのファイルオブジェクト、PC、ライブラリ。
  - **Win+X メニュー**：「スタートボタンの右クリック / Win+X」の高度なメニューを管理（グループ表示、オン/オフ、カスタム項目の追加、削除）。
  - **送る（SendTo）**：右クリック「送る」サブメニューの項目を管理。オン/オフ、追加、削除が可能。
  - **新規作成（ShellNew）**：右クリック「新規作成」サブメニューに表示されるファイル種類を管理、項目ごとにオン/オフ。
  - **ドラッグ＆ドロップハンドラー（DragDrop）**：右クリックでファイルをドラッグ＆ドロップした際に出るメニュー拡張を管理。
  - **プログラムから開く（Open with）**：「プログラムから開く」の候補として登録されたアプリを表示（読み取り専用）。
- **デュアルビューのリアルタイム同期**
  - **ビジュアルビュー（WYSIWYG）**：Windows の実際の右クリックメニューを 1:1 で再現。名前をクリックして改名、アイコンをクリックして変更、**メニュー項目を右クリックすると操作メニューが表示（改名 / アイコン変更 / 有効・無効）**、見たままが得られる。
  - **リストビュー（List View）**：伝統的なテーブル形式、チェックボックスでまとめて選択、オン/オフスイッチ、改名・アイコン変更ボタンを完備、一度に多数のメニュー項目を管理するのに最適。
- **一括マジック**：複数のメニュー項目をチェックし、ワンクリックで全部に同じサフィックス（例「 にゃ~」「 ★」）を追加、カスタマイズも可能。
- **Windows 11 ゾーン**
  - **クラシックメニューのワンクリック切り替え**：HKCU に空の `InprocServer32` を書き込んで新版メニュー拡張を無効化し、エクスプローラーを Win10 のクラシックメニューにフォールバックさせる。さらに `explorer.exe` をスマートに再起動し、メニューが即座に反映、ログオフ・再ログオン不要。もう一度クリックすれば元に戻せます。
  - **新版メニュー拡張（開発中）**：Win11 の `IExplorerCommand` スパースパッケージ（MSIX）拡張項目をスキャンして引き受けるインターフェースを予約。
- **多言語**：初回起動時にシステムの表示言語で自動選択（中国語の簡体/繁体、それ以外はすべて英語）、UI はいつでも切り替え可能。
- **完全ローカル・可逆**：現在のユーザーのレジストリのみを読み書きし、ネットワークにつながず、アップロードもせず、キーを削除すればシステム既定に戻る。

## 使い方

### 1 · 場面を選ぶ

左サイドバーにすべての右クリック場面が縦に並び、3 つのグループに分かれます：

- **よく使う場面**：デスクトップの空白部分、ファイル、フォルダー、フォルダーの空白部分、ドライブ、ごみ箱、すべてのファイルオブジェクト、PC、ライブラリ —— それぞれ異なるオブジェクトを右クリックしたときに見えるメニューに対応。
- **サブメニュー**：送る、新規作成、ドラッグ＆ドロップ、プログラムから開く、ファイルの種類 —— 右クリックメニュー内のサブメニューと拡張子ごとの管理。
- **ショートカット入口**：Win+X（スタートボタンの右クリックの高度なメニュー）。

上部にはさらに **Windows 11 ゾーン** と **リッチメディア** の 2 つの独立した入口があります。任意の場面をクリックするとその場面の実際のメニュー項目をスキャンし、タブのバッジに項目数が表示されます。

### 2 · メニューを編集する

2 つのビューがあり、右上で切り替え、データはリアルタイムに同期します：

- **ビジュアルビュー**：Windows の右クリックメニューを 1:1 で再現。
  - メニュー項目の **名前** をクリックして直接改名、**アイコン** をクリックしてアイコンを変更。
  - 任意のメニュー項目を **右クリック** すると操作メニューが表示：改名 / アイコン変更 / 有効・無効 / 削除（自作項目）。
  - モダンメニュー側は読み取り専用プレビュー（Win11 のモダンメニューはレジストリの制御を受けません、下記の説明を参照）、クラシックメニュー側は編集可能。
- **リストビュー**：伝統的なテーブル形式、一括操作に最適。
  - 各行にオン/オフスイッチ、改名 / アイコン変更ボタン。
  - 複数行をチェックした後、**一括マジック** でワンクリックして統一したサフィックス（例「 ★」）を追加、カスタマイズも可能。

改名 / アイコン変更 / オン・オフはシステム標準の項目に対して再確認します。レジストリへの書き込みのたびに `%LOCALAPPDATA%\ContextMenuMaster\backups\` に自動バックアップされるので、壊しても復元できます。

### 3 · クラシックメニューを取り戻す（Windows 11）

**Windows 11 ゾーン** に入り、「クラシックメニューに切り替え」をクリック：新版メニュー拡張を無効化し `explorer.exe` をスマートに再起動、右クリックメニューが即座に Win10 の完全なスタイルに戻り、ログオフ・再ログオン不要。もう一度クリックすれば新版メニューに戻ります。

### 4 · 自分のメニュー項目を新規作成する

リストビューのツールバーで「メニュー項目を新規作成」をクリックし、表示名、実行タイプ（プログラムを実行 / フォルダーを開く / URL を開く / カスタムコマンドライン）、ターゲットパス、アイコン（任意、あらゆる画像を自動で ICO に変換可能）、位置（先頭 / 末尾）を入力。自作項目には専用の印が付き、いつでも編集・削除でき、削除は本ツールが作成した項目のみを消し、システムの関連付けには触れません。

> **Win11 モダンメニューについて**：Windows 11 の新版右クリックメニューは、パッケージ識別子（MSIX / スパースパッケージ）付きの `IExplorerCommand` 拡張のみを受け入れ、従来のレジストリメニュー項目はすべて「その他のオプションを表示」のクラシックメニューに折りたたまれます —— これはシステムの設計であり、権限とは無関係です。したがって本ツールが管理するのはクラシックメニュー層です。よく使う項目を最上位に戻したい場合は、上記の「クラシックメニューを取り戻す」を使ってください。

## 多言語

C++ バックエンドが Win32 API でシステム既定の表示言語を読み取り、WebView2 ページの作成前にフロントエンドへ注入します：

- システムが中国語（zh-CN / zh-TW / zh-HK など）→ 簡体/繁体に応じて中国語 UI を描画。
- システムがその他のいずれかの言語 → 一律に英語（en）へフォールバック。

UI 右上で簡体 / 繁体 / English をいつでも手動で切り替えられ、選択はローカルストレージに記録されます。

## 技術スタックとアーキテクチャ

| 層 | 選定 | 説明 |
|---|---|---|
| バックエンドエンジン | モダン C++17 / MSVC | Win32 API をネイティブに直接呼び出し |
| プレゼンテーション層 | Microsoft Edge WebView2 | webview 単一ヘッダーライブラリがシステム同梱の WebView2 を担う |
| 通信ブリッジ | WebMessage / postMessage | `w.bind` でバックエンド関数を公開、フロントエンドが `await window.fn()` で呼び出し |
| UI | Vue 3（ローカル） | 単一ファイルアプリケーション |
| ビジュアルシステム | FairyGlass | 微かな青みのダーク液体ガラスデザインシステム、トークンをインラインで `ui/index.html` に複製 |
| ビルド | CMake + Ninja | VS2022「フォルダーを開く」で即認識 |

**アーキテクチャ：Core-Shell（汎用カーネル + ネイティブシェル）**、姉妹プロジェクト FairySave と同様：`src/platform/windows` は Win32 特権層（i18n 検出、レジストリメニューの引き受け）、`ui/` はプレゼンテーション層です。

**互換性**：Windows 10 / 11（クラシックメニューの引き受けは Win11 の機能）。WebView2 ランタイムが必要（Win10/11 に同梱）。

## 開発とビルド

**環境**：VS2022（C++ デスクトップワークロード、CMake、Ninja、Windows SDK を含む）+ WebView2 ランタイム。

**最も簡単な方法**：VS2022「ローカルフォルダーを開く」で本ディレクトリを選択、自動的に `CMakePresets.json` を読み CMake プロジェクトとして認識、`windows-debug` または `windows-release` プリセットを選んでビルド・実行。

**コマンドライン方式**（vcvars64 環境下）：

```bat
cmake --preset windows-release
cmake --build build/release
```

生成物：

- `build/release/bin/ContextMenuMaster.exe` —— GUI メインプログラム（WIN32 サブシステム、コンソールなし）。
- `build/release/bin/CmmCli.exe` —— コマンドラインのデバッグプローブ（バックエンド検証用、エンドユーザー向けではない）。

> `ui/` を編集後、HTML のみを変更した場合は、`ui/` を exe の隣の `ui/` ディレクトリへ手動で同期する必要があります（CMake の POST_BUILD は再リンク時にのみトリガーされます）。

## プライバシーとセキュリティ

- **完全ローカル**：ネットワークにつながず、いかなる内容もアップロードしません。
- **管理者権限が必要**：サードパーティ製ソフトのメニュー項目は多くが `HKLM`（全ユーザー）に登録され、その無効化の印も多くが `HKLM` にあり、純粋なユーザー権限では変更できません。そのためプログラム起動時に管理者権限を要求し、メニュー項目が実際に存在するレジストリの場所を直接読み書きして、「すべての項目をオン・オフ / 改名できる」ことを実現します。
- **書き込み前に自動バックアップ**：レジストリを変更するたびに、まず `reg export` で対応するキーをローカルの `%LOCALAPPDATA%\ContextMenuMaster\backups\` にバックアップします。
- **可逆**：クラシックメニューの引き受けはいつでもキーを削除して復元。オン・オフは「無効化の印を追加/削除 / 無効化ミラーへ移動」方式で、そのまま元に戻せます。項目の削除は必ずごみ箱に送ります。システムファイルは壊しません。

- プリコンパイル版は [Releases](https://github.com/Henglie/ContextMenuMaster/releases) を参照：CPU アーキテクチャで zip を選択（x64 / x86 / arm64）、解凍後 `ContextMenuMaster.exe` をダブルクリックするだけ、インストール不要。大半の PC は x64 を選択。
- WebView2 ランタイムが必要（Windows 10/11 に同梱）。
